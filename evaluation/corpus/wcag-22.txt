指南 1.1：文本替代
成功标准 1.1.1 非文本内容：除了控件、时间型媒体、测试、感官体验、验证码和装饰等明确例外，
所有非文本内容都应为用户提供等效的文本替代。图片的替代文本应说明其用途，
装饰性图片应让辅助技术忽略。

指南 1.4：可辨识
成功标准 1.4.3 对比度（最低）要求普通文本与背景至少达到 4.5:1，大号文本至少达到 3:1。
成功标准 1.4.10 回流要求内容在不损失信息或功能的情况下，以 320 CSS 像素宽度呈现，
对应 1280 CSS 像素宽页面放大 400% 的情形；二维内容、数据表和特定功能除外。

指南 2.5：输入方式
成功标准 2.5.8 目标大小（最低）要求指针输入目标至少为 24×24 CSS 像素，
或者与它周围至少 24 CSS 像素直径的圆形区域没有重叠。行内文本、用户代理控件、
必要尺寸或视觉等效等情形可以例外。
