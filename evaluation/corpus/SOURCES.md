# 评测资料说明

固定题集使用 8 份公开资料的短摘录，覆盖文档问答、制度查询和知识学习三个场景。每个文本文件首部记录原始地址和许可；摘录保留回答问题所需的原文句子，不包含模型生成的答案。

资料在评测时通过公开 API 上传到独立知识库，由真实 worker、Ollama `bge-m3-local` 和真实生成模型处理。评测结果必须记录模型标识、语料文件哈希、应用提交和运行时间。

来源包括：

- IETF RFC 9110 与 RFC 9309。
- W3C WCAG 2.2。
- Creative Commons Attribution 4.0 International。
- Python 3.12 官方教程。
- MDN HTML 与 CSS Grid 文档。

这些文件是验收语料，不是产品内置知识。更新任一文件后必须重新运行全部问题，不能混用旧结果。
